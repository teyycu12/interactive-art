每場活動的資料各自分開，同一時間只會開啟一場。

    使用方式

    1. 準備按「＋ 創建活動」，進控制台排好節目單和題目。
    2. 開始按「切換到這場」，請大家用手機掃 QR Code 進場。
    3. 休息按「暫停」手機暫時進不來；按「重新開始」恢復，資料都在。

    活動中不要切換場次，場上的人會被請出去。刪除活動後無法復原。
